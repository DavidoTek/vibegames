Privacy

This game is a static website hosted on GitHub Pages. GitHub receives your IP address when you load it (see GitHub's privacy statement).

Solo play sends nothing anywhere.

Online play uses PeerJS to connect two browsers directly. To set up the connection, your browser contacts the free PeerJS server (0.peerjs.com) and Google's STUN server, and, if needed, a PeerJS relay server. These receive your IP address and connection data. The other player also sees your IP address. Game data goes directly between the two browsers, encrypted.

Your name, settings and best times are only stored in your browser.
